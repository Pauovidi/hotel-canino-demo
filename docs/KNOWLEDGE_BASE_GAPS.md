# Knowledge Base Gaps

This file lists business content that is not safe to invent from the repo.

## Gaps

- Minimum puppy age / cachorro policy: no official rule exists in the repo. The bot must ask for age/vaccines and mark the case for team review.
- Full "what the stay includes" detail: the repo has reliable FAQ fragments, but no single official exhaustive policy. The bot can offer categories and answer covered topics.
- Live availability: the repo has an operational availability check, but it needs required reservation details and must not be replaced by a generic yes/no answer.
- Complex medical, behavioral, emergency, aggressive/reactive or severe anxiety cases: FAQ classifier already routes these toward human review.
- Waitlist: not enabled as an automatic promise unless current policy explicitly supports it.

## Non-Gaps Already Covered

- Reception hours.
- Published hotel/guardería prices.
- Bath-size published snippets.
- Payment guidance.
- Vaccines/cartilla/microchip.
- Food and medication FAQ.
- Location/contact.
- Booking process and WhatsApp confirmation.
- Contract acceptance link flow.
